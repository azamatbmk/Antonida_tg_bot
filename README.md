# Antoinida — Telegram-бот курса

NestJS-бот: оплата начального курса танцев через самозанятые.рф, выдача первого урока и инвайта в канал, следующие уроки — после подтверждения преподавателя.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Напишите боту, затем узнайте свой Telegram id (например через `@userinfobot`).
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `OWNER_TELEGRAM_IDS`.
4. Установите зависимости и базу:

```bash
npm install
npx prisma generate
npx prisma db push
npm run start:dev
```

5. В боте откройте `/start`. Пока нет `SELFWORK_API_KEY`, оплата тестовая — кнопка «Тестовая оплата».
6. Преподаватель присылает файлы с номером в начале имени: `01 Разминка и постановка корпуса.mp4`.
7. Создайте приватный канал, добавьте бота админом с правом приглашать, пропишите `CHANNEL_ID` (например `-100…`).

## Оплата самозанятые.рф

В кабинете Кошелька включите смарт-оплату и callback на:

`https://ваш-домен/payments/selfwork/callback?token=СЕКРЕТ`

Секрет положите в `SELFWORK_CALLBACK_SECRET`. Редирект после оплаты: `https://ваш-домен/pay/success`.

`PUBLIC_URL` должен быть тем же доменом — бот шлёт ученику ссылку `/pay/{orderId}`.
